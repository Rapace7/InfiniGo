# 玄清围弈 · RapaceGo

> 一个 Windows 桌面围棋工具：**跟 AI 下棋、看客观数据、听本地模型用大白话讲棋。**
> 引擎和模型都在你自己电脑上跑，不联网、不上传棋谱。

## 这是什么

市面上不缺围棋软件，这个想解决的是一个具体问题：**下完一盘棋，知道自己哪里错了、为什么错。**

所以它把两件事拼在一起：

| 谁 | 干什么 |
|---|---|
| **KataGo**（引擎） | 算得准 —— 胜率、目差、推荐点、形势、每手亏几目。客观数字，不会瞎夸。 |
| **LoGos**（本地小模型） | 讲得清 —— 用大白话讲「这一手为什么好 / 差、当时 AI 想下哪」。 |

两个装在一起才最好用：**「好不好」由 KataGo 的数字说了算，「为什么」听 LoGos 讲。**
（这也是我坚持的分工 —— 让语言模型自己评价棋，实测它会对着明显差棋编出一套好话。）

## 能做什么

### 对弈
- **人机对弈**：KataGo 的人类棋风模型，难度是**业余段位标尺**（20 级 – 9 段），另可选「前 AI 时代段位」和「职业棋风 · 按年份」
- **让子**：按标准做（预先摆的是黑子、摆完白先走、不贴目）
- **摆棋 / 双人**：两边都由你下，用来研究变化；从摆棋切回人机时会先问你「AI 执哪一方」
- **试下**：从当前局面打草稿，不影响正式对局
- 9 / 13 / 19 路，四种规则（中国 / 日本 / 韩国 / 明清还棋头）
- **计时**：超快棋 – 世界大赛五档，带读秒提示音、**超时判负**

### 看数据
- **胜率条 + 目数**（形势一眼可见）、**推荐点**（圈内数字是搜索量）、**变化图**（鼠标停在推荐点上）
- **形势图**：雾 / 方块两种画法，快死的子自动变淡
- **走势图**：胜率 / 目差双纵轴，标出失误点
- **手数列表**：每一手都带「涨跌」，点一下跳到那一手
  （**算准了才显示数字** —— 刚落那一手先显示「…」，出数字之后就不会再自己变）
- **复盘报告**：整盘逐手重算，**黑白分开**统计平均目损、失误手数、与 AI 首选的一致率、分阶段表现

### 听讲解（和别的围棋软件最不一样的地方）
- **分析讲解**：点评当前显示的那一手 —— 好坏看 KataGo 的胜率涨跌，为什么听 LoGos 讲。**每手各存一份**，切到哪手看哪手
- **选点讲解**：给出几个推荐点（点位和胜率来自 KataGo），每个点分别讲理由
- **全盘讲解**：打开棋谱后一次把整盘逐手讲完，**结果跟着棋谱存起来**，下次打开直接看，不用重跑

![全盘讲解](docs/screenshots/batch-progress.png)

### 棋谱库与棋谱自带的解说词
导入 / 导出 / 备注 / 删除 / 搜索，列表里标出「已复盘」「带讲解」。

**棋谱自带的解说词**（很多下载来的棋谱里写着，尤其是职业棋谱和题集）：
右下角「解说词」框显示**当前这一手**的解说，点「编辑」能直接改，改完**存回原文件**
（第一次改会留一份 `.bak` 备份）。

- 棋谱**开头**那段说明（题集出处、第几图、谁整理的）显示在「**（开局前 · 棋谱说明）**」那一档 ——
  翻到最开头就能看到，也可以编辑后存回
- 打谱、复盘、讲解都基于这份棋谱，改动只落在**那一条**解说词上，别处一字不动
- 解说词里的**空行会被收掉**：职业棋谱的解说常是一句一行的弹幕体，空行多半是导出工具排版留下的
- 题集类的棋谱（一份文件串着好几道题）顶栏会标出「**第 N 题 / 共 M 题**」——
  只标位置、**不做跳转**（跳题会牵扯手数范围、引擎请求、历史、缓存四处状态）

### 引擎手动加载
打开软件**一个引擎都不加载**（不占显存），想摆棋打谱直接用；要用 AI 时点顶栏的灯：

![引擎状态灯](docs/screenshots/engine-menu.png)

**灯右边那个「刷新」是急救键** —— 遇到「推荐点不出来 / 棋盘上方那行『计算中… N』
定住不动 / 点了没反应」这类像是卡住的情况，点它一下：会放开卡住的分析、重排一次、
重新查引擎状态，引擎真挂了就顺手重启。平时点它也没关系（等于刷新 + 把当前局面重算一遍）。

## 硬件要求

**主要门槛是显存** —— KataGo 和讲解模型都住在显存里。

| | 最低 | 推荐 |
|---|---|---|
| 系统 | Windows 10 / 11 64 位 | 同 |
| 内存 | 8 GB | 16 GB |
| 显卡 | 4GB 显存的独显（或核显，能跑 KataGo 就行） | **8GB 显存**（RTX 3060 / 4060 以上） |
| 硬盘 | 约 2 GB | 约 8 GB（要装讲解模型的话） |

显存实测（RTX 4070 Laptop / 8GB，用 `nvidia-smi` 量）：

| 组件 | 占用 |
|---|---|
| KataGo 分析引擎（胜率、推荐点、形势、复盘） | ≈ **350 MB** |
| KataGo 对弈引擎（AI 落子） | ≈ **170 MB** |
| LoGos 讲解模型（Q4_K_M，7B） | ≈ **4.9 GB** |
| **三个全开** | ≈ **5.5 GB** |

所以：

- **6GB 显存的卡能用**，但别三个一起开（先卸载对弈引擎或讲解模型）
- **4GB 显存 / 核显**：只能用 KataGo 那部分功能，讲解会一直提示「讲解模型还没加载」
- **想三个一起开，就要有 8GB**

> 正因为这样，软件**默认一个引擎都不加载** —— 你不用 AI 就不占显存；
> 要用时点顶栏的灯，讲完可以随时卸载。

**没有独显也能用**：KataGo 支持纯 CPU 模式（设置面板里能改），慢但能下棋。
讲解模型在 CPU 上也能跑，但速度会掉到每秒几个字，基本没法用。

## 下载与安装（一步一步照着做）

全程约 10 分钟（不含下载时间）。
**只想下棋、不要讲解功能的话，跳过第 3 步就行 —— 能省 4.4GB 的下载。**

### 第 1 步 · 下载软件

**① 打开下载页**：**<https://github.com/Rapace7/RapaceGo/releases>**

**② 往下滑到「发布 / Releases」那一段，找最上面那条** ——
标题写着版本号（`v0.1.10` 这样的号，每次更新都会变）。
GitHub 把下载文件都放在「发布 / Releases」里，认准**最上面那条**就对了。

> ⚠️ **别去找固定的版本号**（比如 `v0.1.0`）—— 那是**最老的那一版，在最下面**。
> 你要的是**最新版 = 列表最上面那条**。

**③ 那个区块下面写着 `Assets`**：

> ⚠️ **Assets 不是一个文件夹**，是这次发布附带的**下载文件清单**。
> 小白最容易在这儿绕晕 —— 你要找的就是这份清单里的文件。

**④ 清单里只有一个 `RapaceGo.zip`（约 146 MB），点它下载**

- ⚠️ **别下页面最下面的 `Source code (zip)`** —— 那是 GitHub 自动生成的**源码**压缩包，
  解压出来不能双击运行

**⑤ 下载完是个 zip 文件：右键 → 全部解压缩**

**⑥ 打开解压出来的文件夹，里面有 `RapaceGo.exe`，双击它** ——
软件能打开了 ✅（AI 功能暂时还不能用，因为还没装引擎，接着往下走）

> 看不懂英文没关系：只要认准三样东西 ——
> ① **最上面那条**发布（标题里的版本号不用记）② 在它下面的 `Assets` 清单里 ③ 点蓝色的 `RapaceGo.zip`。

### 第 2 步 · 装围棋引擎（必需，不装就没有 AI 下棋和数据分析）

**2.1 下载引擎程序**

1. 打开 **<https://github.com/lightvector/KataGo/releases>**
2. 找最新版本，往下滑到 **Assets**，下载**文件名里带 `windows` 的 `.zip`**
   （别下 `.tar.gz` —— 那是给 Linux / macOS 的）
3. 解压 → 得到一个 `katago` 文件夹

**2.2 下载两个模型文件（权重）**

1. 打开 **<https://katagotraining.org/>**
2. 找到 **Networks** 那一栏，下载这两个：

| 文件 | 干什么用 |
|---|---|
| `b11c768nbt.bin.gz` | 算胜率、推荐点、形势、复盘（"强"模型） |
| `b18c384nbt-humanv0.bin.gz` | **当 AI 对手**用（⚠️ 就是文件名带 `human` 的那个） |

> ⚠️ 这两个 `.bin.gz` 看着像压缩包，但 **不要解压** —— 程序自己会读。

**2.3 摆对位置**

整理成下面这样。**引擎要放在软件旁边**，和 `RapaceGo.exe` 平级：

```
RapaceGo/                         ← 解压出来的文件夹（有 70 多个文件，见下面说明）
├─ RapaceGo.exe                   ← 双击启动（程序本体）
├─ …（一堆 .dll / .pak / locales\ 等）← 软件自带的运行库，别删
├─ KataGo/                        ← 你把 2.1 解压出来的文件夹整个改名成 "KataGo"
│  ├─ katago.exe
│  ├─ …（同目录里还有一堆 .dll，一起放着别删）
│  └─ weights/                    ← 新建这个文件夹
│     ├─ b11c768nbt.bin.gz
│     └─ b18c384nbt-humanv0.bin.gz
└─ LoGos/                         ← 第 3 步才需要
```

> 💡 **解压后不要被"文件好多"吓到** —— 程序本体其实是一整套（约 368 MB），
> 其中 `RapaceGo.exe` 一个就 245 MB（框架和代码都在里面），其余是它的运行库
> （`*.dll`、`*.pak`、`locales\`、`resources\`）。**看不懂的不要删**，你要动的只有
> `KataGo/`、`LoGos/` 这两个文件夹和「设置」里的路径。
> 完整清单（哪些自带、哪些自动生成、哪些能删）见 `发布说明.md`。

**2.4 在软件里指定位置**

1. 左上角点「**设置**」
2. 找到「**KataGo 程序**」那一行，点「**选择…**」，选第 2.1 步里的 `katago.exe`
   （💡 选完它会**自动帮你把两个权重的路径也填上**，不用手选）
3. 点「**保存并重启引擎**」

### 第 3 步 · 装讲解模型（可选，要下 4.4GB）

讲解功能要额外下一个 4.4GB 的模型。**最省事的办法是双击一个文件，不需要敲任何命令**：

1. 下载的包里有 **`下载讲解模型.bat`**
2. **双击它** —— 它会自动下载并合并模型、装好推理运行时（共约 5GB 流量）
3. 中间会弹一个黑色窗口，进度在动就**等着别关掉**
4. 看到「**搞定了！**」就完成了
5. 回到软件左上角「设置」→ **LoGos** 那一组，两行路径分别点「选择…」：
   - 选 `LoGos\llama-server.exe`
   - 选 `LoGos\LoGos-7B-Q4_K_M.gguf`
6. 点「**保存并重启引擎**」

> 网络中断了不用怕 —— **重新双击那个文件会接着上次的地方继续下**。

> **已经自己下载了 `LoGos-7B-Q4_K_M.gguf.part01 / .part02 / .part03` 那三个分卷？**
> 那就不用管上面的 bat 了 —— 往下看 **▶ 点这里展开** 那段，一行命令就能合并。

<details>
<summary><b>▶ 点这里展开：已经自己下好那三个分卷了？也可以手动合并（不用 bat）</b></summary>

从 Releases 页面直接下 `LoGos-7B-Q4_K_M.gguf.part01 / .part02 / .part03` 的话，
**任选下面一种方式合并成 `LoGos-7B-Q4_K_M.gguf`** 即可（放在同一个文件夹里）。

**① 命令行一行（最省事）** —— 把三行连起来敲：

```bat
copy /b LoGos-7B-Q4_K_M.gguf.part01+LoGos-7B-Q4_K_M.gguf.part02+LoGos-7B-Q4_K_M.gguf.part03 LoGos-7B-Q4_K_M.gguf
```

**② PowerShell（逐块流式拷贝，内存占用低）**

```powershell
$out = [System.IO.File]::Create("LoGos-7B-Q4_K_M.gguf")
foreach ($p in "part01","part02","part03") {
  $i = [System.IO.File]::OpenRead("LoGos-7B-Q4_K_M.gguf.$p")
  $i.CopyTo($out); $i.Close()
}
$out.Close()
```

**③ 用 7-Zip / WinRAR 之类** —— 这些工具没有"合并分卷"功能，**不行**。

**⚠️ 合并完必须核对**：文件应该是 **4,466,xxx,xxx 字节（约 4.36 GB）**。
对不上就是下载不全，把三个 `.part` 删掉重下。核对：

```bat
dir LoGos-7B-Q4_K_M.gguf
```

合并成功后可以删掉那三个 `.part`（省 4.4GB 空间）。
然后回软件「设置」→ LoGos 组选 `llama-server.exe` 和合并出来的 `.gguf` 即可。

> 顺便说明：GitHub 单个文件硬上限 2GB，所以 4.4GB 的模型只能分卷上传 ——
> 这是**平台限制**，不是故意的。分卷合并就是纯二进制拼接，
> 和 `split` / `cat` 生成的结果完全一致（开发时用 sha256 校验过）。

## 你的数据都存在哪（便携式说明）

**全部在这个文件夹里，不会跑到别处去**：

```
RapaceGo/
├─ RapaceGo.exe
├─ records/          ← 你的棋谱（.sgf），以及每份棋谱的复盘报告和逐手讲解
├─ engine-logs/      ← 引擎日志（排错用，随时可删）
├─ userdata/         ← 软件自己的页面缓存（自动生成，可随时删）
├─ settings.json     ← 你在「设置」里填的引擎路径
├─ KataGo/           ← 你自己放的引擎
└─ LoGos/            ← 你自己放的讲解模型
```

**想彻底卸载**：关掉软件，**把整个 `RapaceGo` 文件夹删掉**就行 ——
不写注册表、不留 C 盘、卸载不留痕。棋谱想留就先复制出来。

唯一的例外：**桌面快捷方式**。只有你主动点「设置 → 在桌面创建快捷方式」时才会建一个
`.lnk`，删掉那个文件即可。

## 如何更新到新版本

**一句话：把新包解压到原来那个文件夹、覆盖同名文件就行 —— 棋谱和设置不会丢。**

### 三步

1. **先看你现在是什么版本** —— 打开软件 → 左上角「**帮助**」→ 标题右边写着 `v0.1.1` 这样的号。
   （下载的包**固定叫 `RapaceGo.zip`、不带版本号**，所以从文件名看不出新旧，只能这么看。）

2. **去发布页看有没有更新的** → <https://github.com/Rapace7/RapaceGo/releases>
   页面**最上面那条就是最新版**，标题里写着版本号和日期。

3. **关掉软件** → 下载新的 `RapaceGo.zip` → **解压到你原来那个文件夹**
   （右键「全部解压缩」，路径选你现在用的文件夹；Windows 问是否覆盖时选「替换」）
   → 重新双击 `RapaceGo.exe`。

### 为什么不会丢东西

包里**只有程序本体**，一点你的数据都不含：

| 你的东西 | 在包里吗 | 更新之后 |
|---|---|---|
| `records\` —— 棋谱、复盘报告、逐手讲解 | ❌ 不在 | **原样保留** |
| `settings.json` —— 你在「设置」里填的路径 | ❌ 不在 | **原样保留** |
| `KataGo\`、`LoGos\` —— 引擎和讲解模型 | ❌ 不在 | **原样保留** |
| `userdata\` —— 软件缓存 | ❌ 不在 | 原样保留（也可以随时删掉，会自动重建） |

> ⚠️ **更新前一定要先关掉软件。** 程序开着的时候文件被占用，覆盖会失败或只覆盖一半 ——
> 表现是「更新完打开还是旧版」，或者软件直接起不来。关掉窗口后**等三五秒**再解压更稳。

### 保险做法（可选）

不放心的话，更新前把 **`records` 文件夹整个复制一份**到别处。
它是唯一**丢了就找不回来**的东西（你的棋谱和讲解）；软件本身随时能从发布页重新下载。

### 版本号是怎么定的

| 哪一位 | 什么时候加 | 例子 |
|---|---|---|
| **第三位** | 修 bug、小改动。**每次发布 +1**，可以频繁 | 0.1.0 → **0.1.1** → 0.1.2 |
| **第二位** | 加了你能明显感觉到的新功能，攒够一个"包"才 +1 | 0.1.x → **0.2.0** |
| **第一位** | 只有 `1.0.0`：稳定到可以推荐给任何人 | |

**不会跳号** —— 每次更新只加第三位，看到 `0.1.1 → 0.1.2` 就是「又修了一批问题」。

## 关于讲解的几个说明

**速度**：本地跑 LoGos，实测一段 150–200 字的讲解约 **2–4 秒**（RTX 4070 Laptop）。
全盘讲一盘 200 手约 **8–12 分钟**（可随时停，停下后再点会**接着讲**，讲过的不重讲）。

**它会说错话**：LoGos 是 7B 的小模型，偶尔会把术语叫错（比如把星位说成小目）。
**位置通常是对的，叫法可能不准** —— 请以 KataGo 的数字为准。

**它只会说中文**（训练数据是中文标注的，给英文 prompt 也照样输出中文）。
所以如果你看不懂中文：**把讲解选起来，丢进任何翻译工具或大模型里翻一下就行** ——
它是一段通俗的白话，翻译过去读起来很顺，围棋术语也能译得出来。

**「全盘讲解」和「AI 复盘」不是一回事**：复盘给的是**数据报告**，全盘讲解给的是**逐手文字**。

## 开发方式（这个项目是怎么来的）

**代码几乎全部由 AI Agent 写**，是一个"人机协作"的实验：

全过程记在 **[开发记录.md](开发记录.md)** —— 它不是普通的更新日志，而是**决策记录**：

想看看"和一个 AI 长期协作做软件"长什么样的话，那份文件可能比代码更有意思。

静态检查（元素引用 / 接口契约 / 隐藏冲突）+ 端到端冒烟 + 跨局竞态回归，
每次改完代码都跑一遍。用法见文件头部注释。

## 常见问题

**Q：打开软件提示「找不到引擎」？**
去左上角「设置」把路径填对。默认约定是把引擎放在项目**上一级**（见上文表格）。

**Q：讲解按钮点了说「讲解模型还没加载」？**
点顶栏那个 `LoGos` 灯 → 「加载」（第一次约十几秒，之后就快了）。
LoGos 平时不加载是**故意的** —— 省显存。

**Q：`llama-server.exe` 起来了但特别慢（几秒一个字）？**
多半是没走 GPU（官方包默认不含 CUDA 运行时）。跑 `llama-server.exe --list-devices` 看看 ——
如果显示 `none`，说明缺 cudart，去 llama.cpp releases 里单独下对应的 `cudart-*.zip` 放到同目录。

**Q：棋谱存在哪？**
软件目录下的 `records\`。想搬走就整个文件夹拷走。

**Q：能不能连模型一起打包发给我朋友？**
别 —— LoGos 的授权是"仅研究、非商业"，而且 4.4GB 也不好分发。让他自己按上面的步骤准备。
