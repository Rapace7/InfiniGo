# 玄清围弈 · InfiniGo

> 一个 Windows 桌面围棋工具：**跟 AI 下棋、看客观数据、听本地模型用大白话讲棋。**
> 引擎和模型都在你自己电脑上跑，不联网、不上传棋谱。

## 这是什么

市面上不缺围棋软件，这个想解决的是一个具体问题：**下完一盘棋，知道自己哪里错了、为什么错。**

所以它把两件事拼在一起：

| 谁 | 干什么 |
|---|---|
| **KataGo**（引擎） | 算得准 —— 胜率、目差、推荐点、形势、每手亏几目。客观数字，不会瞎夸。 |
| **LoGos**（本地小模型） | 讲得清 —— 用大白话讲「这一手为什么好 / 差、当时 AI 想下哪」。 |

两个装在一起才最好用：**「好不好」由 KataGo 的数字说了算，「为什么」听 LoGos 讲。**
（这也是我坚持的分工 —— 让语言模型自己评价棋，实测它会对着明显差棋编出一套好话。）

## 能做什么

### 对弈
- **人机对弈**：KataGo 的人类棋风模型，难度是**业余段位标尺**（20 级 ~ 9 段），另可选「前 AI 时代段位」和「职业棋风 · 按年份」
- **让子**：按标准做（预先摆的是黑子、摆完白先走、不贴目）
- **摆棋 / 双人**：两边都由你下，用来研究变化；从摆棋切回人机时会先问你「AI 执哪一方」
- **试下**：从当前局面打草稿，不影响正式对局
- 9 / 13 / 19 路，四种规则（中国 / 日本 / 韩国 / 明清还棋头）
- **计时**：超快棋 ~ 世界大赛五档，带读秒提示音、**超时判负**

### 看数据
- **胜率条 + 目数**（形势一眼可见）、**推荐点**（圈内数字是搜索量）、**变化图**（鼠标停在推荐点上）
- **形势图**：雾 / 方块两种画法，快死的子自动变淡
- **走势图**：胜率 / 目差双纵轴，标出失误点
- **手数列表**：每一手都带「涨跌」，点一下跳到那一手
- **复盘报告**：整盘逐手重算，**黑白分开**统计平均目损、失误手数、与 AI 首选的一致率、分阶段表现

### 听讲解（和别的围棋软件最不一样的地方）
- **分析讲解**：点评当前显示的那一手 —— 好坏看 KataGo 的胜率涨跌，为什么听 LoGos 讲。**每手各存一份**，切到哪手看哪手
- **选点讲解**：给出几个推荐点（点位和胜率来自 KataGo），每个点分别讲理由
- **全盘讲解**：打开棋谱后一次把整盘逐手讲完，**结果跟着棋谱存起来**，下次打开直接看，不用重跑

![全盘讲解](docs/screenshots/batch-progress.png)

### 棋谱库
导入 / 导出 / 备注 / 删除 / 搜索，列表里标出「已复盘」「带讲解」。

### 引擎手动加载
打开软件**一个引擎都不加载**（不占显存），想摆棋打谱直接用；要用 AI 时点顶栏的灯：

![引擎状态灯](docs/screenshots/engine-menu.png)

## 快速开始

### ⚠️ 先说清楚：本仓库**不含引擎和模型**

这里只有软件本身的代码（600KB 左右）。要真正跑起来，你需要自己准备两个引擎 ——
**它们是别人的项目，各有各的许可，不适合塞进这个仓库**：

| 需要的东西 | 从哪来 | 放哪 |
|---|---|---|
| **KataGo** 程序 | [lightvector/KataGo](https://github.com/lightvector/KataGo/releases) 的 Windows 版 | `<项目上级目录>\KataGo\engine\katago.exe` |
| **KataGo 权重**（两个） | [katagotraining.org](https://katagotraining.org/) —— 一个**强**模型（算胜率） + 一个**带 human 的模型**（当对手） | `<项目上级目录>\KataGo\weights\*.bin.gz` |
| **llama.cpp** 运行时 | [ggml-org/llama.cpp](https://github.com/ggml-org/llama.cpp/releases)，要 CUDA 版（**别忘了另下 cudart 包，官方的主包不含 CUDA 运行时**） | `<项目上级目录>\LoGos\llama-server.exe` |
| **LoGos-7B** 权重 | [YichuanMa/LoGos-7B](https://huggingface.co/YichuanMa/LoGos-7B)（转成 GGUF，推荐 Q4_K_M，约 4.4GB） | `<项目上级目录>\LoGos\LoGos-7B-Q4_K_M.gguf` |

> **为什么是"上一级目录"**：软件默认就去**它旁边的 `KataGo\` 和 `LoGos\`** 找引擎。
> 比如项目在 `D:\GoStudy\GoMate`，那引擎就放 `D:\GoStudy\KataGo` 和 `D:\GoStudy\LoGos`。
> 想放别处也行 —— 在软件的「设置」里改，或设环境变量 `GOMATE_KATAGO` / `GOMATE_LOGOS`。

**只想下棋不想装讲解**？也可以：只配 KataGo 那三项，讲解功能不用就行。
**显卡**：LoGos 的 Q4 权重约占 4.4GB 显存，8GB 的卡放得下；它和 KataGo 不宜同时全速跑，所以平时不加载。

### 跑起来

```bat
git clone https://github.com/Rapace7/InfiniGo.git
cd InfiniGo
npm install
双击 start.bat
```

国内网络 `npm install` 慢的话，项目里的 `.npmrc` 已经配好了镜像（npmmirror + Electron 镜像），直接装就行。

### 配路径

打开软件 → 左上角「设置」→ 分两组填路径（KataGo 组 / LoGos 组），每一项旁边有个 **`?`**，
鼠标停上去会告诉你这一项是什么、去哪里找：

![设置面板](docs/screenshots/settings-help.png)

> 选「KataGo 程序」时会自动去它旁边翻权重，找到就替你填上。
> **最容易踩的坑**：对弈权重一定得选**文件名带 human** 的那个 —— 拿普通权重当对手，引擎会直接报错退出。

## 关于讲解的几个说明

**速度**：本地跑 LoGos，实测一段 150~200 字的讲解约 **2~4 秒**（RTX 4070 Laptop）。
全盘讲一盘 200 手约 **8~12 分钟**（可随时停，停下后再点会**接着讲**，讲过的不重讲）。

**它会说错话**：LoGos 是 7B 的小模型，偶尔会把术语叫错（比如把星位说成小目）。
**位置通常是对的，叫法可能不准** —— 请以 KataGo 的数字为准。

**「全盘讲解」和「AI 复盘」不是一回事**：复盘给的是**数据报告**，全盘讲解给的是**逐手文字**。

## 开发方式（这个项目是怎么来的）

**代码几乎全部由 AI Agent 写**，是一个"人机协作"的实验：

| 角色 | 干什么 |
|---|---|
| **人** | 定方向、拍板功能、判断好不好用、验收效果 |
| **AI Agent**（运行在 [WorkBuddy](https://www.workbuddy.cn/docs/workbuddy/Overview) 上） | 写代码、查资料、跑测试、写文档、修 bug |

本项目的开发对话由 **DeepSeek V4.1 Flash** 驱动。

全过程记在 **[开发记录.md](开发记录.md)** —— 它不是普通的更新日志，而是**决策记录**：
每个功能为什么这么做、哪些方案被否掉了、踩过哪些坑、实测数据是什么。
想看看"和一个 AI 长期协作做软件"长什么样的话，那份文件可能比代码更有意思。

**测试是认真的**：项目根目录的 `_*.mjs` / `_rtest.py` 是一套自检工具 ——
静态检查（元素引用 / 接口契约 / 隐藏冲突）+ 端到端冒烟 + 跨局竞态回归，
每次改完代码都跑一遍。用法见文件头部注释。

## 常见问题

**Q：打开软件提示「找不到引擎」？**
去左上角「设置」把路径填对。默认约定是把引擎放在项目**上一级**（见上文表格）。

**Q：讲解按钮点了说「讲解模型还没加载」？**
点顶栏那个 `LoGos` 灯 → 「加载」（第一次约十几秒，之后就快了）。
LoGos 平时不加载是**故意的** —— 省显存。

**Q：`llama-server.exe` 起来了但特别慢（几秒一个字）？**
多半是没走 GPU（官方包默认不含 CUDA 运行时）。跑 `llama-server.exe --list-devices` 看看 ——
如果显示 `none`，说明缺 cudart，去 llama.cpp releases 里单独下对应的 `cudart-*.zip` 放到同目录。

**Q：棋谱存在哪？**
软件目录下的 `records\`。想搬走就整个文件夹拷走。

**Q：能不能连模型一起打包发给我朋友？**
别 —— LoGos 的授权是"仅研究、非商业"，而且 4.4GB 也不好分发。让他自己按上面的步骤准备。
