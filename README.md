# 玄清围弈 · RapaceGo

> 一个 Windows 桌面围棋工具：**跟 AI 下棋、看客观数据、听本地模型用大白话讲棋。**
> 引擎和模型都在你自己电脑上跑，不联网、不上传棋谱。

## 这是什么

市面上不缺围棋软件，这个想解决的是一个具体问题：**下完一盘棋，知道自己哪里错了、为什么错。**

所以它把两件事拼在一起：

| 谁 | 干什么 |
|---|---|
| **KataGo**（引擎） | 算得准 —— 胜率、目差、推荐点、形势、每手亏几目。客观数字，不会瞎夸。 |
| **LoGos**（本地小模型） | 讲得清 —— 用大白话讲「这一手为什么好 / 差、当时 AI 想下哪」。 |

两个装在一起才最好用：**「好不好」由 KataGo 的数字说了算，「为什么」听 LoGos 讲。**
（这也是我坚持的分工 —— 让语言模型自己评价棋，实测它会对着明显差棋编出一套好话。）

## 能做什么

### 对弈
- **人机对弈**：KataGo 的人类棋风模型，难度是**业余段位标尺**（20 级 – 9 段），另可选「前 AI 时代段位」和「职业棋风 · 按年份」
- **让子**：按标准做（预先摆的是黑子、摆完白先走、不贴目）
- **摆棋 / 双人**：两边都由你下，用来研究变化；从摆棋切回人机时会先问你「AI 执哪一方」
- **试下**：从当前局面打草稿，不影响正式对局
- 9 / 13 / 19 路，四种规则（中国 / 日本 / 韩国 / 明清还棋头）
- **计时**：超快棋 – 世界大赛五档，带读秒提示音、**超时判负**

### 看数据
- **胜率条 + 目数**（形势一眼可见）、**推荐点**（圈内数字是搜索量）、**变化图**（鼠标停在推荐点上）
- **形势图**：雾 / 方块两种画法，快死的子自动变淡
- **走势图**：胜率 / 目差双纵轴，标出失误点
- **手数列表**：每一手都带「涨跌」，点一下跳到那一手
- **复盘报告**：整盘逐手重算，**黑白分开**统计平均目损、失误手数、与 AI 首选的一致率、分阶段表现

### 听讲解（和别的围棋软件最不一样的地方）
- **分析讲解**：点评当前显示的那一手 —— 好坏看 KataGo 的胜率涨跌，为什么听 LoGos 讲。**每手各存一份**，切到哪手看哪手
- **选点讲解**：给出几个推荐点（点位和胜率来自 KataGo），每个点分别讲理由
- **全盘讲解**：打开棋谱后一次把整盘逐手讲完，**结果跟着棋谱存起来**，下次打开直接看，不用重跑

![全盘讲解](docs/screenshots/batch-progress.png)

### 棋谱库
导入 / 导出 / 备注 / 删除 / 搜索，列表里标出「已复盘」「带讲解」。

### 引擎手动加载
打开软件**一个引擎都不加载**（不占显存），想摆棋打谱直接用；要用 AI 时点顶栏的灯：

![引擎状态灯](docs/screenshots/engine-menu.png)

## 硬件要求

**主要门槛是显存** —— KataGo 和讲解模型都住在显存里。

| | 最低 | 推荐 |
|---|---|---|
| 系统 | Windows 10 / 11 64 位 | 同 |
| 内存 | 8 GB | 16 GB |
| 显卡 | 4GB 显存的独显（或核显，能跑 KataGo 就行） | **8GB 显存**（RTX 3060 / 4060 以上） |
| 硬盘 | 约 2 GB | 约 8 GB（要装讲解模型的话） |

显存实测（RTX 4070 Laptop / 8GB，用 `nvidia-smi` 量）：

| 组件 | 占用 |
|---|---|
| KataGo 分析引擎（胜率、推荐点、形势、复盘） | ≈ **350 MB** |
| KataGo 对弈引擎（AI 落子） | ≈ **170 MB** |
| LoGos 讲解模型（Q4_K_M，7B） | ≈ **4.9 GB** |
| **三个全开** | ≈ **5.5 GB** |

所以：

- **6GB 显存的卡能用**，但别三个一起开（先卸载对弈引擎或讲解模型）
- **4GB 显存 / 核显**：只能用 KataGo 那部分功能，讲解会一直提示「讲解模型还没加载」
- **想三个一起开，就要有 8GB**

> 正因为这样，软件**默认一个引擎都不加载** —— 你不用 AI 就不占显存；
> 要用时点顶栏的灯，讲完可以随时卸载。

**没有独显也能用**：KataGo 支持纯 CPU 模式（设置面板里能改），慢但能下棋。
讲解模型在 CPU 上也能跑，但速度会掉到每秒几个字，基本没法用。

## 下载与安装（一步一步照着做）

全程约 10 分钟（不含下载时间）。
**只想下棋、不要讲解功能的话，跳过第 3 步就行 —— 能省 4.4GB 的下载。**

### 第 1 步 · 下载软件

**① 打开下载页**：**<https://github.com/Rapace7/RapaceGo/releases>**

**② 往下滑，找到一个写着 `v0.1.0 · 首次发布` 的区块** ——
GitHub 把下载文件都放在「发布 / Releases」里，认准这个标题就对了。

**③ 那个区块下面写着 `Assets`**：

> ⚠️ **Assets 不是一个文件夹**，是这次发布附带的**下载文件清单**。
> 小白最容易在这儿绕晕 —— 你要找的就是这份清单里的文件。

**④ 点清单里的 `RapaceGo.zip`（147 MB）下载**

- 旁边的 `RapaceGo.exe` 也能用，但它是单文件、每次启动要先解压，慢一两秒
- ⚠️ **别下页面最下面的 `Source code (zip)`** —— 那是 GitHub 自动生成的**源码**压缩包，
  解压出来不能双击运行

**⑤ 下载完是个 zip 文件：右键 → 全部解压缩**

**⑥ 打开解压出来的文件夹，里面有 `RapaceGo.exe`，双击它** ——
软件能打开了 ✅（AI 功能暂时还不能用，因为还没装引擎，接着往下走）

> 看不懂英文没关系：只要认准三样东西 ——
> ① 找标题 `v0.1.0 · 首次发布` ② 在它下面的 `Assets` 清单里 ③ 点蓝色的 `RapaceGo.zip`。

### 第 2 步 · 装围棋引擎（必需，不装就没有 AI 下棋和数据分析）

**2.1 下载引擎程序**

1. 打开 **<https://github.com/lightvector/KataGo/releases>**
2. 找最新版本，往下滑到 **Assets**，下载**文件名里带 `windows` 的 `.zip`**
   （别下 `.tar.gz` —— 那是给 Linux / macOS 的）
3. 解压 → 得到一个 `katago` 文件夹

**2.2 下载两个模型文件（权重）**

1. 打开 **<https://katagotraining.org/>**
2. 找到 **Networks** 那一栏，下载这两个：

| 文件 | 干什么用 |
|---|---|
| `b11c768nbt.bin.gz` | 算胜率、推荐点、形势、复盘（"强"模型） |
| `b18c384nbt-humanv0.bin.gz` | **当 AI 对手**用（⚠️ 就是文件名带 `human` 的那个） |

> ⚠️ 这两个 `.bin.gz` 看着像压缩包，但 **不要解压** —— 程序自己会读。

**2.3 摆对位置**

整理成下面这样。**引擎要放在软件旁边**，和 `RapaceGo.exe` 平级：

```
RapaceGo/
├─ RapaceGo.exe
├─ KataGo/                      ← 2.1 解压出来的文件夹，整个改名成 "KataGo"
│  ├─ katago.exe
│  ├─ …（同目录里还有一堆 .dll，一起放着别删）
│  └─ weights/                  ← 新建这个文件夹
│     ├─ b11c768nbt.bin.gz
│     └─ b18c384nbt-humanv0.bin.gz
└─ LoGos/                       ← 第 3 步才需要
```

**2.4 在软件里指定位置**

1. 左上角点「**设置**」
2. 找到「**KataGo 程序**」那一行，点「**选择…**」，选第 2.1 步里的 `katago.exe`
   （💡 选完它会**自动帮你把两个权重的路径也填上**，不用手选）
3. 点「**保存并重启引擎**」

### 第 3 步 · 装讲解模型（可选，要下 4.4GB）

讲解功能要额外下一个 4.4GB 的模型。**最省事的办法是双击一个文件，不需要敲任何命令**：

1. 下载的包里有 **`下载讲解模型.bat`**
2. **双击它** —— 它会自动下载并合并模型、装好推理运行时（共约 5GB 流量）
3. 中间会弹一个黑色窗口，进度在动就**等着别关掉**
4. 看到「**搞定了！**」就完成了
5. 回到软件左上角「设置」→ **LoGos** 那一组，两行路径分别点「选择…」：
   - 选 `LoGos\llama-server.exe`
   - 选 `LoGos\LoGos-7B-Q4_K_M.gguf`
6. 点「**保存并重启引擎**」

> 网络中断了不用怕 —— **重新双击那个文件会接着上次的地方继续下**。

### 第 4 步 · 加载引擎，开始用

⚠️ 软件**打开时故意一个引擎都不加载**（不占你的显存、也不拖慢启动）。

要用 AI 时点**顶栏**的灯：

```
  KataGo    LoGos
   ○         ○      ← 刚打开都是灰的（未加载）
```

点一下灯 → 菜单里选「**加载**」→ **灯变绿就是就绪**（两个都是十几秒）。

| 你想做什么 | 需要加载 |
|---|---|
| 下棋、看胜率/形势/数据、复盘 | 只要 **KataGo** |
| 另外还要看讲解 | 再加 **LoGos** |
| 不用了 | 菜单里点「**卸载**」，显存立刻释放 |

### 想从源码跑（改代码 / 看看它怎么写的）

```bat
git clone https://github.com/Rapace7/RapaceGo.git
cd RapaceGo
npm install
双击 start.bat
```

源码模式下引擎要放在**项目的上一级**，或在「设置」里填路径。
`.npmrc` 里已经带国内镜像，`npm install` 不会太慢。


## 关于讲解的几个说明

**速度**：本地跑 LoGos，实测一段 150–200 字的讲解约 **2–4 秒**（RTX 4070 Laptop）。
全盘讲一盘 200 手约 **8–12 分钟**（可随时停，停下后再点会**接着讲**，讲过的不重讲）。

**它会说错话**：LoGos 是 7B 的小模型，偶尔会把术语叫错（比如把星位说成小目）。
**位置通常是对的，叫法可能不准** —— 请以 KataGo 的数字为准。

**它只会说中文**（训练数据是中文标注的，给英文 prompt 也照样输出中文）。
所以如果你看不懂中文：**把讲解选起来，丢进任何翻译工具或大模型里翻一下就行** ——
它是一段通俗的白话，翻译过去读起来很顺，围棋术语也能译得出来。

**「全盘讲解」和「AI 复盘」不是一回事**：复盘给的是**数据报告**，全盘讲解给的是**逐手文字**。

## 开发方式（这个项目是怎么来的）

**代码几乎全部由 AI Agent 写**，是一个"人机协作"的实验：

| 角色 | 干什么 |
|---|---|
| **人** | 定方向、拍板功能、判断好不好用、验收效果 |
| **AI Agent**（运行在 [WorkBuddy](https://www.workbuddy.cn/docs/workbuddy/Overview) 上） | 写代码、查资料、跑测试、写文档、修 bug |

本项目的开发对话由 **DeepSeek V4.1 Flash** 驱动。

全过程记在 **[开发记录.md](开发记录.md)** —— 它不是普通的更新日志，而是**决策记录**：
每个功能为什么这么做、哪些方案被否掉了、踩过哪些坑、实测数据是什么。
想看看"和一个 AI 长期协作做软件"长什么样的话，那份文件可能比代码更有意思。

**测试是认真的**：项目根目录的 `_*.mjs` / `_rtest.py` 是一套自检工具 ——
静态检查（元素引用 / 接口契约 / 隐藏冲突）+ 端到端冒烟 + 跨局竞态回归，
每次改完代码都跑一遍。用法见文件头部注释。

## 常见问题

**Q：打开软件提示「找不到引擎」？**
去左上角「设置」把路径填对。默认约定是把引擎放在项目**上一级**（见上文表格）。

**Q：讲解按钮点了说「讲解模型还没加载」？**
点顶栏那个 `LoGos` 灯 → 「加载」（第一次约十几秒，之后就快了）。
LoGos 平时不加载是**故意的** —— 省显存。

**Q：`llama-server.exe` 起来了但特别慢（几秒一个字）？**
多半是没走 GPU（官方包默认不含 CUDA 运行时）。跑 `llama-server.exe --list-devices` 看看 ——
如果显示 `none`，说明缺 cudart，去 llama.cpp releases 里单独下对应的 `cudart-*.zip` 放到同目录。

**Q：棋谱存在哪？**
软件目录下的 `records\`。想搬走就整个文件夹拷走。

**Q：能不能连模型一起打包发给我朋友？**
别 —— LoGos 的授权是"仅研究、非商业"，而且 4.4GB 也不好分发。让他自己按上面的步骤准备。
